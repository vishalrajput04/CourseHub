# 🎓 CourseHub

CourseHub is a modern and responsive online course platform built using **React.js, Tailwind CSS, and Vite**. It provides a clean and user-friendly interface for exploring different programming and technology courses.

## ✨ Features

* 📚 Browse different courses
* 💰 Free and paid courses
* ⭐ Course ratings
* ⏱️ Course duration
* 📱 Responsive design
* 🧭 React Router navigation
* 🔐 Login and Logout functionality
* ⚛️ Reusable React components
* 🎨 Modern UI with Tailwind CSS
* 📄 Multiple pages

## 🛠️ Technologies Used

* **React.js**
* **JavaScript**
* **Tailwind CSS**
* **React Router DOM**
* **Vite**
* **HTML5**
* **CSS3**

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/your-username/CourseHub.git
```

### Go to the Project Directory

```bash
cd CourseHub
```

### Install Dependencies

```bash
npm install
```

### Run the Project

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.
